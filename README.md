# Security Analyst Portfolio 🛡️

Welcome to my Security Analyst Portfolio. This repository showcases practical cybersecurity skills, bridging the gap between application development, academic research, and active network defense. It contains hands-on demonstrations of network reconnaissance, perimeter security, web application vulnerabilities, and comprehensive threat research.

## 📂 Repository Structure & Completed Tasks

This portfolio is divided into four primary modules, mixing practical technical demonstrations with analytical research. 

### [Task 1: Basic Network Scanning with Nmap](./Nmap-Scanning)
* **Objective:** Perform network reconnaissance to identify open ports, running services, and operating systems.
* **Concepts Covered:** Attack surface mapping, service enumeration, port risk analysis.
* **Deliverables:** Technical documentation, Nmap scan results, and a video demonstration.

### [Task 2: Basic Firewall Configuration with UFW](./UFW-Firewall)
* **Objective:** Secure a Linux environment by configuring Uncomplicated Firewall (UFW) rules to filter incoming and outgoing traffic.
* **Concepts Covered:** Traffic filtering, default deny policies, perimeter defense.
* **Deliverables:** Bash configuration script, rule justification report, and a video demonstration.

### [Task 3: SQL Injection on DVWA](./SQLi-DVWA)
* **Objective:** Exploit a classic SQL Injection vulnerability on the Damn Vulnerable Web Application (DVWA) to understand application-layer risks.
* **Concepts Covered:** Input validation failures, database exposure, parameterized queries.
* **Deliverables:** Payload analysis, exploitation screenshots, mitigation strategies, and a video demonstration.

### [Task 4: Common Network Security Threats Report](./Network-Threats)
* **Objective:** A structured research report analyzing modern network threats, real-world case studies, and mitigation techniques.
* **Concepts Covered:** DoS/DDoS, Man-in-the-Middle (MITM), IP Spoofing, and DNS Poisoning.
* **Deliverables:** A comprehensive `.md` research report with industry references.
